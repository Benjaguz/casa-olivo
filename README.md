# Casa Olivo
## General

Esta pequeña página se trata sobre un restaurante ficticio, más específicamente de su carta virtual, la idea es facilitar la búsqueda de opciones de comida a la hora de ordenar, pudiendo filtrar entre gustos o necesidades.

Fue elaborada con Claude Code, estoy aprendiendo a usarlo y hice bastantes modificaciones con ayuda de esta herramienta, traté de no limitarme a la primera versión que entrega.
